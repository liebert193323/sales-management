# 📊 Sales Management App

Aplikasi manajemen penjualan berbasis Flutter yang dirancang untuk membantu pelaku bisnis dalam mengelola data produk, pelanggan, dan transaksi penjualan secara efisien.

## 🚀 Fitur Utama

🔐 Autentikasi Pengguna (Login/Logout)

📦 Manajemen Produk (Tambah, Edit, Hapus)

👥 Manajemen Pelanggan

🧾 Pencatatan Transaksi Penjualan

📈 Dashboard Ringkasan Penjualan

🔍 Pencarian dan Filter Data

📱 Desain Responsif dan Mudah Digunakan

## 🛠️ Teknologi yang Digunakan

- [Flutter](https://flutter.dev/) (versi terbaru)
)
